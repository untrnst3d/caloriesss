# NutriDay

Учебный счётчик калорий на React и Python. Это третья рабочая версия проекта — 0.0.3. В каталоге есть примерные значения КБЖУ на 100 г, можно добавить собственный продукт, сохранить именованную порцию и записать приём пищи в дневник на выбранную дату. Данные хранятся локально в SQLite.

## Возможности

- 18 исходных продуктов и добавление своих с калориями, белками, жирами, углеводами.
- Расчёт КБЖУ для произвольного веса порции.
- Сохранение своей порции с названием и весом для выбранного продукта.
- Дневник по датам, приёмам пищи и сумма КБЖУ за день; удаление записи.
- Сохранение продуктов, порций и дневника после перезапуска приложения.

Показатели продуктов приведены для учебного примера; для точного расчёта проверяйте упаковку. Анкета и рецепты относятся к следующим версиям.

## Файлы

- `app.py` — FastAPI, API, SQLite, создание таблиц и начальный список продуктов.
- `App.jsx` — страница React и запросы к серверу.
- `style.css` — оформление страницы.
- `index.html` — точка входа браузера.
- `vite.config.js` — передача запросов `/api` серверу Python.
- `requirements.txt` и `package.json` — используемые библиотеки.
- `package-lock.json` — зафиксированные версии npm.
- `отчет_30.09.26.md` — общий отчёт с этапами за 30.09.2026 и 06.10.2026.
- `nutriday.sqlite3` создаётся автоматически рядом с `app.py` при запуске и не добавляется в Git.

## Запуск

Нужны Python 3.12+ и Node.js 22.12+. Откройте папку репозитория в VS Code и два терминала. Оба терминала должны оставаться открытыми.

Терминал 1, macOS/Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --reload --port 8000
```

Терминал 1, Windows PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app:app --reload --port 8000
```

Терминал 2:

```bash
npm ci
npm run dev
```

Откройте адрес из терминала Vite, обычно `http://localhost:5173`. Если порт 5173 занят, остановите ранее запущенный Vite или выполните `npm run dev -- --port 5174`. Проверить сервер отдельно можно на `http://localhost:8000/api/products`, интерактивный список адресов — на `http://localhost:8000/docs`.

## Как связаны части

React отправляет `GET /api/products` и `GET /api/diary?day=ГГГГ-ММ-ДД` для чтения; `POST /api/products`, `POST /api/portions`, `POST /api/diary` для сохранения; `DELETE /api/diary/{id}` для удаления записи. Vite перенаправляет `/api` на Uvicorn по порту 8000. FastAPI проверяет введённые данные и работает с SQLite через стандартный модуль Python `sqlite3`. Docker и отдельный сервер базы не нужны.

Это локальный учебный прототип для одного пользователя. Регистрации и синхронизации между устройствами нет. Чтобы начать с пустого дневника, при остановленном сервере можно удалить только локальный файл `nutriday.sqlite3`: таблицы и исходные продукты появятся при следующем запуске.

## Новое в 0.0.3

- Ввод названия активности и потраченных калорий вручную.
- Список активности за выбранную дату и удаление записи.
- Сохранение в новой таблице `activities` в SQLite.
- Сумма калорий активности и показатель «Еда минус активность». Это простое вычитание, а не остаток суточной нормы: основной обмен здесь не учитывается.
- Проверка пустого названия, даты и положительного количества калорий.

API: `GET /api/activities?day=2026-10-10`, `POST /api/activities`, `DELETE /api/activities/{id}`.

## Переход со второй версии

Останови прежние сервер и Vite. Распакуй архив в отдельную папку. Чтобы сохранить свои данные, скопируй `nutriday.sqlite3` из старой папки рядом с новым `app.py`, затем запусти проект командами выше. Новая таблица создастся автоматически. Старую папку оставь как резервную копию.

В архиве нет чужой базы, `.venv`, `node_modules` и истории Git. Это локальная версия для проверки, не опубликованный релиз. Отчёт нового этапа: `Отчет_v0.0.3.md`.
