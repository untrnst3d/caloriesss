# NutriDay 0.0.4

Учебный локальный счётчик калорий: React, FastAPI и SQLite. Четвёртая версия добавляет профиль и дневную цель. Продукты, порции, дневник по датам и активность из версии 0.0.3 сохранены.

## Запуск на Mac

Установи Python 3.12+ и Node.js 22.12+. Распакуй архив и открой папку Caloriesss_v0.0.4 в VS Code. В двух терминалах этой папки выполни:

Терминал 1:
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --reload --port 8000
```
Терминал 2:
```bash
npm ci
npm run dev
```
Открой адрес, который напечатал Vite. Обычно это http://localhost:5173; если порт занят, Vite выберет следующий. Оба терминала оставь открытыми. Для остановки нажми Ctrl+C.

Windows: вместо создания окружения используй `py -3 -m venv .venv`, а вместо `.venv/bin/python` — `.venv\Scripts\python.exe`. Команды npm те же.

## Как пользоваться

Открой «Профиль», введи пол, возраст, рост, вес, активность и цель. Нажми «Сохранить профиль». На вкладке «Дневник» появятся цель, съеденные калории, остаток или превышение и полоска прогресса. Изменение анкеты применяется только после успешного сохранения. Один профиль хранится локально; регистрации нет.

Расчёт ориентировочный для взрослых 19–78 лет. Основа — формула Миффлина — Сан Жеора: 10 × вес в кг + 6.25 × рост в см − 5 × возраст + 5 для мужчин или −161 для женщин. Источник: https://pubmed.ncbi.nlm.nih.gov/2305711/

Учебные настройки приложения: коэффициенты активности 1.2 / 1.375 / 1.55 / 1.725; цель «похудеть» умножает результат на 0.9, «сохранить» на 1, «набрать» на 1.1. Нижний порог — 1500 ккал для мужчин и 1200 для женщин. Эти настройки и пороги не являются медицинским назначением или гарантией безопасности. При заболеваниях, беременности и кормлении нужна индивидуальная оценка специалиста.

Ручная активность отображается отдельно и не прибавляется к цели: обычная нагрузка уже включена коэффициентом. Текущая цель применяется ко всем выбранным датам; история изменений цели в этой версии не хранится.

## Переход с третьей версии

Останови сервер старой версии. Сохрани резервную копию старой папки. Скопируй файл `nutriday.sqlite3` из старой папки в новую рядом с `app.py`. Затем запусти новую версию. Таблица `profile` создастся автоматически; старые таблицы и записи не удаляются. Если базу не переносить, приложение создаст новую с 18 исходными продуктами.

## Файлы

- `app.py` — сервер, модели, SQL и расчёт цели.
- `App.jsx` — интерфейс, формы и обращения к API.
- `dailyGoal.js` — остаток калорий и процент прогресса.
- `style.css`, `index.html` — оформление и входная страница.
- `vite.config.js` — порт и прокси API.
- `package.json`, `package-lock.json`, `requirements.txt` — зависимости и команды.
- `tests/test_profile.py`, `tests/dailyGoal.test.js` — проверки новой функциональности.

Новые API: `GET /api/profile` читает анкету; `PUT /api/profile` сохраняет или обновляет её. Ответ содержит `profile` и `calculation`. API продуктов, порций, дневника и активности остались прежними. Документация сервера: http://localhost:8000/docs.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
node --test tests/dailyGoal.test.js
npm run build
```
Python-проверки работают с временной базой и не изменяют пользовательскую. Сборка создаёт папку `dist`; для работы по-прежнему нужен Python-сервер. В архив не включены база пользователя, окружение Python, node_modules, dist и отчёты предыдущих этапов.
