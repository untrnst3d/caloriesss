# NutriDay

Учебный проект: приложение для учёта питания. В репозитории находится первый рабочий прототип — небольшой список продуктов. Цель этого этапа: показать обмен данными между React и сервером Python.

## Что реализовано

- Сервер возвращает список из трёх продуктов и калорийность каждого на 100 г.
- Кнопка «Загрузить продукты» получает данные через API и выводит их на странице.
- Если сервер недоступен, появляется сообщение об ошибке.

На первом этапе продукты заданы в `app.py`. База данных, дневник и личный кабинет планируются позже.

## Структура

```text
caloriesss/
├── app.py             # Python-сервер и список продуктов
├── App.jsx            # интерфейс React
├── index.html         # страница приложения
├── vite.config.js     # передача запросов /api на Python-сервер
├── requirements.txt   # зависимости Python
├── package.json       # зависимости и команды React
├── package-lock.json  # точные версии пакетов
├── .gitignore
└── README.md
```

Приложение использует Python, FastAPI, JavaScript, React и Vite. После нажатия на кнопку React отправляет запрос `GET /api/products`. Сервер отвечает списком в формате JSON, после чего React выводит продукты.

## Запуск

Нужны Python 3.12+ и Node.js 22.12+. Команды выполняются в папке проекта. Откройте два терминала.

**Терминал 1 — сервер.**

macOS/Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --reload --port 8000
```

Windows (PowerShell):

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app:app --reload --port 8000
```

**Терминал 2 — интерфейс:**

```bash
npm ci
npm run dev
```

Откройте адрес, который покажет Vite в терминале (обычно `http://localhost:5173`), и нажмите «Загрузить продукты». Должны появиться яблоко, банан и молоко. Если порт 5173 занят, Vite выберет следующий свободный. Ответ сервера отдельно виден по адресу `http://localhost:8000/api/products`. Оба терминала должны оставаться открытыми; остановка — `Ctrl+C`.
