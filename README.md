# NutriDay — версия для бесплатного хостинга

Начните с **HOSTING.md**. Схема: Render Free + Neon Free. Ничего не опубликовано.

- frontend/ — неизменённый интерфейс React.
- backend/ — Python API, локальный SQLite или внешний PostgreSQL.
- tests/ — проверки логики и переноса данных.
- render.yaml — бесплатный сервис, без диска и платной БД Render.
- Dockerfile — сборка фронтенда и запуск бэкенда по одному адресу.
- compose.yaml — локальная демонстрация с SQLite.

Локальные проверки пройдены. Облачную БД требуется проверить через tests/postgres_check.py до публикации и переноса реальных данных. Подробные шаги, ограничения и правила переноса — в HOSTING.md.
